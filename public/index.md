# The Grid Nexus

The Grid Nexus is the trust layer for gamers — plain-language gaming security.

- **Security grades** for games and platforms: <https://thegridnexus.com/games>
- **"Is it safe?" verdicts** on mods, cheats, and scams: <https://thegridnexus.com/safety>
- **Account recovery** guides (Steam, Discord, Epic, EA, Riot, PlayStation, Xbox): <https://thegridnexus.com/recover>
- **Gamer threat report** (CISA KEV triaged by gamer impact): <https://thegridnexus.com/threats>
- **Data** (grades, verdicts, recovery playbooks — CC BY 4.0): <https://thegridnexus.com/data>

## Tools

- Scam Checker: <https://thegridnexus.com/tools/scam-check>
- Gaming Security Checkup: <https://thegridnexus.com/tools/gaming-security-checkup>

## About

Document-based, cited guidance. The Grid Nexus never asks for passwords or account credentials, and never recovers accounts on a user's behalf.

- Full text corpus: <https://thegridnexus.com/llms-full.txt>
- API catalog: <https://thegridnexus.com/.well-known/api-catalog>
