# Authentication

The Grid Nexus public content and data require **no authentication**.

- Public data (game grades, safety verdicts, recovery playbooks) is served without a key: <https://thegridnexus.com/data>
- No API key, token, or login is required to read the site or its data.
- The Grid Nexus never asks users for passwords, two-factor codes, or recovery codes.

For machine-readable page content, send `Accept: text/markdown` and the server returns a Markdown version of the page.
